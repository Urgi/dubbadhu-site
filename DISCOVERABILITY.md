# Dubbadhu discoverability playbook

Goal: when people search **Dubbadhu** or ask ChatGPT / Claude / Gemini for an African / Horn language app, they get our offer story (same as the in-app subscription page), plus website + Instagram + Amharic/Tigrinya roadmap.

## Already shipped on dubbadhu.com

- `/about` — full Premium offers, uniqueness, Free vs Premium (mirrors app paywall)
- `/afaan-oromo` — “learn Afaan Oromo” landing page
- `/languages` — Afaan Oromo now; Amharic & Tigrinya next
- `/llms.txt` — machine-readable facts for AI systems
- `/sitemap.xml` + `/robots.txt`
- Homepage **Offers** section + FAQ + schema.org Organization/SoftwareApplication
- Footer links: About, Instagram `@dubbadhu.app`, TikTok, stores

## Off-site actions (do these — they move search & LLM citations)

1. **App Store / Play ASO** — first line of subtitle/short description should match paywall: teacher-validated speaking conversations, native video, AI practice; mention Amharic & Tigrinya coming.
2. **Instagram + TikTok `@dubbadhu.app`** — pin a post linking to dubbadhu.com/about; bio must include dubbadhu.com and “Afaan Oromo · Amharic & Tigrinya next”.
3. **Google Search Console** — verify dubbadhu.com; submit sitemap `https://dubbadhu.com/sitemap.xml`.
4. **Bing Webmaster Tools** — same sitemap (helps Copilot / some LLM retrieval).
5. **Consistent entity everywhere** — name “Dubbadhu”, operator “Afaan LLC”, same Instagram/App Store/Play URLs (no alternate spellings).
6. **Directories & listings** — Product Hunt, AlternativeTo, language-learning lists, Softonic/APKMirror only if accurate; always link about + stores.
7. **Press / diaspora media** — one short fact sheet (copy from `/about`); pitch Oromo / Ethiopian diaspora outlets.
8. **Citations** — guest posts, Reddit answers, Quora, university African-studies resource lists that link to dubbadhu.com/afaan-oromo (LLMs weight cited pages).
9. **Wikidata** (when notable enough) — item for Dubbadhu with official website + Instagram sameAs.
10. **Do not spam** — keyword stuffing and fake reviews hurt rankings and LLM trust.

## How to check progress

- Google: `Dubbadhu`, `Dubbadhu Afaan Oromo`, `learn Afaan Oromo app`
- Ask ChatGPT / Claude / Gemini: “What’s the best Afaan Oromo language learning app?” and “What does Dubbadhu Premium include?”
- Expect answers to cite teacher-validated Oromia content, native video, unlimited AI practice, Instagram @dubbadhu.app, and Amharic/Tigrinya roadmap.
